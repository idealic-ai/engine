# Mode: `page` — build or fix one page

> **Role**: You build or repair exactly one artifact, end to end, and you verify it by looking at it.
>
> **Goal**: A page that demonstrates its subject honestly, measures its own claims, and states what it could not establish.
>
> **Mindset**: The specimen is the test. A number you did not measure is a number you do not have. If you cannot demonstrate something honestly, say so on the page — a named absence is a stronger result than a filled slot.

**Phase names** (specializing the shared skeleton):
- **1 Orient → Ground**: read sources; **never re-derive a measured fact** — read it from `FACTS.md`.
- **2 Work → Build**: compose the one artifact.
- **3 Adjudicate → Verify**: the mode's spine (below) — four mandatory parts.

---

## Phase 1 — Ground

`LOAD-DIGEST`. Read the sources for the subject and the `FACTS` rows that already establish its numbers. If a number you need is not in the ledger, you must **measure it** (and append it), not guess it — but never re-derive one the ledger already holds.

## Phase 2 — Build

Compose the single artifact. **Real content only** — a fabricated demo of a real behaviour is the one thing that invalidates the page. Where colour encodes, register/read the channel from `REGISTRY` and ship the `legend` (`¶INV_DS_ENCODE_OR_OMIT`, `¶INV_DS_NON_COLOUR_CHANNEL`). Declare, on the page, whether it **inlines** the kit (a dated specimen, frozen by design) or **links** it (a live demo that breaks loudly).

## Phase 3 — Verify (the spine — four parts, all mandatory)

1. **Render** the config's full render matrix — every theme × every viewport (for `warm-print`: light AND dark at 1400 AND 390).
2. **Open every PNG.** Not a metaphor — the images are the primary instrument for the glyph class of defect, which no DOM assertion can see (`¶INV_DS_LOOK_AT_IT`).
3. **Assert both** body overflow **and** per-element clipping, naming the clipper. The first alone certified pages that were destroying 234 px of prose (`¶INV_DS_ASSERT_THE_LOSS`).
4. **Print a control before any measurement.** A parser control before any contrast ratio; an isolation control proving the layer survived isolation. One trap manufactures failures; its inverse manufactures **passes** — and a pass is never re-examined.

Append every measurement to `FACTS.md` (`APPEND-FACT`) with how it was measured.

---

## Hard rules

- **Real content only.** A fabricated demo of a real behaviour invalidates the page.
- **Declare inline-vs-linked**, on the page.
- **Name what you could not reproduce**, on the page, rather than staging a repro that proves only that you staged it (`couldNotEstablish` is a real result).
- **Report the defects you shipped and fixed**, and how each was caught — the provenance of a catch is data about the checks.
- **Print controls** — a measurement with no control is not a measurement.

## Report proof (carry into the debrief)

`artifact` · `rendersOpened` · `measurementsWithControls` · `defectsFoundByRender` · `defectsFoundByCheck` · `couldNotEstablish`.
