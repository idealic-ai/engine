# Remix Log
**Usage**: Track a remix cycle — dispatches, builds, sweeps, critiques, measurements, and rulings.
**Requirement**: Every entry header MUST use a `## ` heading. Timestamps are auto-injected by `log.sh`.

## ▶️ Started
*   **Mode**: [orchestrate / page / tend / critique]
*   **Subject**: "The axis / page / sweep target / page to critique."
*   **Digest**: "Loaded PREAMBLE + FACTS rows [ids] + REGISTRY. Freshness: [stamp]."

## 🎨 RULING
*   **Decided**: "What was ruled."
*   **Why**: "The rationale the next agent inherits (a ruling is not a preference)."
*   **Reaction from**: "Human eye / source verification."

## 📤 Dispatch (orchestrate)
*   **Cycle**: [n]
*   **Units**: "File-disjoint units + owner agent each."
*   **Brief cites**: "FACTS ids + REGISTRY channels handed over (never hand-copied numbers)."
*   **Relay**: "Any mid-flight vocabulary correction relayed to siblings."

## 📐 Measurement
*   **Claim**: "What was measured."
*   **Number**: "The value + how measured + control printed."
*   **FACTS id**: "Appended as [id]."

## 🔴 Defect
*   **Class**: [geometry / glyph / semantic]
*   **Found by**: [render / check]
*   **What the reader loses**: "The actual loss (¶INV_DS_ASSERT_THE_LOSS)."

## 👁️ Looked (¶INV_DS_LOOK_AT_IT)
*   **Renders opened**: "light 1400 / dark 1400 / light 390 / dark 390 — all four."
*   **Saw**: "What the eye caught that no check did."

## 🔧 Progress
*   **Action**: "What I did."
*   **Notes**: "Context or reasoning."

## 🚧 Block
*   **Obstacle**: "What's in the way."
*   **Next**: "What I'll try next."

## ✅ Done
*   **Summary**: "landed / deferred / ticketed for each finding (orchestrate); artifact + rendersOpened (page); defectsRepaired + digestRegenerated (tend); findingsByClass (critique)."
*   **Facts appended**: "[ids]."
