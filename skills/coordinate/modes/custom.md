# Custom Mode (User-Defined)
*Read all 3 named modes, then accept user's configuration.*

**Role**: Defined by user.
**Goal**: Defined by user.
**Mindset**: Defined by user.

## Setup
1. Read `autonomous.md`, `cautious.md`, and `supervised.md` to understand the flavor space.
2. Ask the user for their desired:
   - Confidence threshold (0.0 - 1.0)
   - Additional escalation categories (beyond the defaults)
   - Logging level (minimal / standard / verbose)
   - Any special rules or constraints
3. Synthesize into a hybrid mode configuration.

## When to Use
When none of the 3 named modes fit. Experienced users who know exactly what autonomy level they want.
