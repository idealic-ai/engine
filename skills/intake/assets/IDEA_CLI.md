# Retired

`IDEA_CLI.md` is retired. It documented **7 of the CLI's 11 verbs** and had zero inbound references —
a partial second copy of a surface that states itself.

so it cannot go stale) and `idea-cli/CLI.md` (the tool's own reference, kept beside the tool).

The live verbs are `start browse check ship generate assemble lint view wire bundle publish` — read
from `idea-cli/idea.ts`, not transcribed. `docs` joins them; see `idea docs --help`.
